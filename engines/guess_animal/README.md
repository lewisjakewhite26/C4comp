# Guess the animal

A ball bounces round a pixel grid and paints an animal in, with a % counter, "guess before the end" title and a name reveal at 100%. Inspired by @everymergestudio's "Guess the Flag" format.

`python3 guess.py art.jpg NAME out.mp4` (add `still 8,16,26` for check frames). Art should be a single animal on a plain light background. Env settings are listed at the top of `guess.py`.

Capybara settings: `CROP=39,734,1133,1958 COLS=64 ROWS=72 CELL=15 K=16 GY0=560 SPD=720 B0=1.0 B1=2.5 BP=1.5` with art `refs/ideas/capybara_blanket_watercolour.jpg`.
