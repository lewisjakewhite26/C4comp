# Space coaster 5-minute countdown

A first-person space rollercoaster countdown timer for the classroom.

- Runs from 05:00 to 00:00, with the biggest drop landing exactly on zero, then a short "Time's up!" end card (5:06 in total).
- The last 10 seconds turn amber, with soft ticks each second and a chime at zero. There are no flashing or strobing effects.
- Music and sound effects are original and synthesised, so there should be no copyright claims.

Files:
- `space_coaster_5min_countdown_1080p.mp4` for the main board or YouTube upload.
- `space_coaster_5min_countdown_720p.mp4` is a lighter copy.

For YouTube, mark the video as "made for kids".
