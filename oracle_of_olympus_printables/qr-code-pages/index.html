Passcode pages (for NFC tags)

Upload this whole qr-code-pages folder to your site. Write each page’s URL onto an NFC tag (or use the mini QR for testing). When you scan a tag on your phone, this page opens — read the 4-digit code to the team for the laptop. Coloured physical cards can all point to the same URL per stop if each team has a different tag, or use one tag per team per stop — your choice.
