# Zonelytime figure clips (3D human outline, teal)
Six 6-second loops, 1080p 30 fps, teal outline with faint fill on pure black: stamp, jump, throw (right and left arm), chop, duck.

Use in CapCut / Resolve / Canva: put the clip above your footage and set blend mode to **Screen** (or Lighten) so the black disappears.

Built from the open CC0 MakeHuman base mesh and rig (not included; the scripts fetch it from github.com/makehumancommunity/makehuman: base.obj, default.mhskel, default_weights.mhw).
