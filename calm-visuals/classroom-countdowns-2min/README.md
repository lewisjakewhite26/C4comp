# Calm scene countdowns, 2 minutes

Four 2-minute classroom countdowns (1080p, 24 fps, 126 seconds: 120 second countdown plus a gentle "Time's up" ending). Large timer, thin progress line, last 12 seconds warm to amber, soft chime at zero, no flashing.

- `zonelytime_snowy_street_2min_countdown.mp4`
- `zonelytime_coffee_shop_2min_countdown.mp4`
- `zonelytime_rainy_window_2min_countdown.mp4`
- `zonelytime_city_rain_2min_countdown.mp4`
- `timer_overlay.py`: draws the timer onto any 1080p video
