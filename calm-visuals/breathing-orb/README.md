# Breathing orb (guided breathing loop)

3:02, 1920x1080, 24 fps, seamless loop. 13 breaths: in 5 s, hold 2 s, out 5 s, hold 2 s.
- `breathing_orb_loop_3min_guide_1080p.mp4` has faint "Breathe in / Hold / Breathe out" text.
- `breathing_orb_loop_3min_clean_1080p.mp4` has no text.
Both videos are silent. Run `./add_audio.sh guide` (or `clean`) to add `ambient_breathing.m4a`, a breath-synced ambient drone that loops seamlessly.
