# City bedroom, rain and thunder (sleep video)

- `city_loop_3min_1080p.mp4`: seamless 3-minute silent loop (1920x1080, 24fps).
- `lightning.json`: times (seconds into the loop) of each lightning flash, so thunder can be timed to them.
- `engine_city.py`: the animation engine (rain on glass, soft lightning, subtle window lights, lamp and duvet breathing).
